# 相関図メーカー（SoukanzuMaker）

キャラクターや組織の関係を示す相関図を、ブラウザだけで作って画像として保存できるツールです。
サーバーを使わないので GitHub Pages にそのまま置いて動きます。作ったデータや取り込んだ画像は外部に送信されません。

## いまできること（雛形 v0.1）

| 分類 | 内容 |
| --- | --- |
| カード | 写真／丸アイコン／横並び／名前のみの4形式。写真がないときは「名前だけ」か「頭文字アイコン」で代替。サブテキスト、バッジ（父・母など）、配色プリセット |
| 写真 | カードへのドラッグ＆ドロップ、コピー＆貼り付け、ファイル選択。取り込み時に大きすぎる画像は縮小 |
| 写真の位置合わせ | 写真をダブルクリックすると、写真全体を薄く表示してドラッグで動かせる。写真枠の中心（十字）と写真の中心（印）を表示し、中央付近では中央に吸い付いて緑色になる。ホイールで拡大縮小、「中央に戻す」 |
| カードの文字 | フォント、文字エリアの高さ（高くすると長い名前は2行に折り返し）、名札の帯の色、バッジの文字サイズ |
| フォント | ゴシック・明朝・丸ゴシック・やわらか丸ゴ・手書き風・マジック風・極太・ポップ（すべて同梱、使う文字の分だけ読み込み）と端末のフォント。カード・枠見出し・矢印ラベル・テキストごとに指定、新規作成時の既定フォント、一括変更 |
| 枠 | 四角・角丸・楕円・多角形。多角形テンプレート（L字・逆L字・T字・凸字・コ字・段付き・六角形・ひし形） |
| 頂点編集 | 多角形をダブルクリック → 頂点のドラッグ・追加・削除。「直角を保つ」モードで辺を水平・垂直のまま変形 |
| 枠の見出し | 見出し＋英字サブ。内側の上／上辺に重ねる／外側の上／内側の下 × 左・中央・右寄せ、位置の微調整、英字サブの文字サイズ、フォント |
| 枠と中身 | 枠を動かすと中のカードも一緒に動く（Alt を押しながらで枠だけ） |
| 矢印 | カード・枠どうしを接続し、移動に追従。直角／直線／曲線、出る辺・入る辺の指定、折れ位置、→ ↔ ← —、線種、太さ、矢じりサイズ、ラベル（位置・背景・縦書き）、関係の種類プリセット |
| 分岐・合流 | 矢印ツールで既存の矢印をクリックすると、そこに分岐点ができて枝を伸ばせる（終点としてクリックすると合流）。分岐点はドラッグで動かせ、画像には出ない（点を描く設定も可） |
| 太さの変化 | 「太さを変える」で始点から終点へ太くなる・細くなる矢印。矢じりも太さに合わせて大きくなる |
| 接続位置 | 矢印を選んで端の□をドラッグすると、接続先のカードや辺、辺上の位置を変えられる（グリッドに吸着、中央に吸い付き） |
| 折れ点 | 矢印を選んで線上の○をドラッグすると折れ点を追加。折れ点はドラッグで移動、ダブルクリックで削除。両端のカードを一緒に動かすと折れ点も付いてくる |
| テキスト・画像 | 自由配置のテキスト（縦書き・縁取り）、画像素材 |
| 配置 | グリッド表示・吸着（操作中の要素だけ）、指定マスごとの太線、「全体を揃える」で全要素をグリッドに合わせ直し、Ctrl（⌘）で吸着を一時反転 |
| 整列ガイド | ドラッグ・大きさ変更中に、他の要素やキャンバスの端・中央と揃う位置に吸い付き、ガイド線を表示（Alt で一時オフ） |
| 合わせる | 揃える基準（選択範囲／最初に選んだ要素／キャンバス）、幅・高さを合わせる、間隔を指定して並べる、枠を中身や選んだカードに合わせる、枠の中央に置く |
| 編集 | 範囲選択、複数選択、元に戻す／やり直し、コピー＆貼り付け、複製、スタイルのコピー＆貼り付け、重なり順、非表示、ロック、レイヤー一覧 |
| 保存 | ブラウザ（IndexedDB）に自動保存。画像込みのプロジェクトファイル（`.soukanzu`、中身は zip）で保存・読み込み |
| 出力 | PNG / JPEG、1〜3倍、背景透過。非表示の要素とグリッドは出力しない |

### ショートカット

| キー | 動作 |
| --- | --- |
| V / H / C / F / T / E | 選択 / 移動 / カード / 枠 / 文字 / 矢印 |
| Ctrl+Z / Ctrl+Shift+Z | 元に戻す / やり直し |
| Ctrl+C / Ctrl+V / Ctrl+D | コピー / 貼り付け / 複製 |
| Ctrl+Shift+C / Ctrl+Shift+V | スタイルをコピー / 貼り付け |
| Delete | 削除 |
| 矢印キー（Shift） | 1px（グリッド1マス）移動 |
| Ctrl+ホイール / スペース＋ドラッグ | 拡大縮小 / 画面の移動 |
| Esc | 矢印作成・頂点編集・選択の解除 |

## まだできないこと（次の段階）

- 複数プロジェクトの一覧管理
- カード・枠の自作スタイルをテンプレートとして保存
- スマホ・タブレットでの編集の作り込み

## 開発

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ に出力
```

構成：Vite + React + TypeScript、描画は Konva（react-konva）、状態管理は zustand、保存は IndexedDB（idb-keyval）、プロジェクトファイルは JSZip、フォントは Noto Sans JP（@fontsource で同梱）。

```
src/
  model/    データ型・初期値・プリセット・幾何計算（矢印の経路、多角形）・サンプル
  store/    状態と元に戻す履歴
  canvas/   キャンバス（Konva）と各図形の描画
  ui/       ツールバー・プロパティ・レイヤーの各パネル
  io/       自動保存・プロジェクトファイル・画像出力
```

## GitHub Pages への公開

`main` に push すると `.github/workflows/deploy.yml` がビルドして公開します。
初回だけ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。
